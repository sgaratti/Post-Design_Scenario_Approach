# Post-Design Scenario Approach Framework

This repository contains MATLAB code implementing examples of application of the **Post-Design Scenario Approach framework**.

## Main scripts

The following MATLAB scripts reproduce examples illustrating the application of the framework:

- `h2control.m`: H2 control example.
- `input_design_example.m`: Input design example.
- `pole_placement.m`: Pole placement example.

## Auxiliary files

The following files contain auxiliary functions and routines required by the main scripts:

- `epsLU_fast.m`
- `solve_mnid.m`
- `test_mnid.m`

These files are auxiliary and are not intended to be run independently.

## Requirements

The code is written in MATLAB. Additional MATLAB toolboxes may be required depending on the example being executed.
